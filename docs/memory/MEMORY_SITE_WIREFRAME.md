## 2. Design System & Iconografia Monocromática
- **Paleta Oficial:** Verde Origem (`#1E2614`), Verde Pomar (`#4F5C13`), Verde Colina (`#9DA300`), Âmbar Solar (`#D89346`), Marfim Natural (`#E7E4C9`).
- **Tipografia:** `IBM Plex Sans Condensed` (Caixa Alta para Destaques/Títulos, Medium/Regular para Corpo).
- **Iconografia Monocromática SVG:** 100% dos emojis foram substituídos por ícones vetoriais monocromáticos SVG em botões, tags, selos e pills.
